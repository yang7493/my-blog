# 학습 노트 만들기

아래 순서대로 해줘.

1. 먼저 나에게 물어봐 — "뭘 배웠어요?"
   내가 답하기 전에는 글을 쓰지 마.
2. 내가 답하면 그 다음 물어봐 — "막혔던 부분이 있었어요?"
   (막힌 게 있었다면) "그거 어떻게 해결했어요? 아직 못 풀었어요?"
   내가 답하기 전에는 글을 쓰지 마.
3. 이 세션 안에서 `learn` 스킬로 학습한 내용이 있는지 확인해.
   있다면 그 내용과 방금 받은 답변(배운 것 / 막힌 것 / 해결한 것)을 합쳐서 글 내용을 구성해.
   `learn` 스킬 내용이 없다면 방금 받은 답변만으로 작성해.
4. 내 답을 가지고 `_posts/`에 글을 만들어줘.
   - 파일 이름과 머리말은 `CLAUDE.md` 규칙을 따라.
   - front matter는 파일 맨 위에 딱 한 번만 써. 절대 두 번 쓰지 마.
   - categories나 tags처럼 배열 값은 `[값1, 값2]`처럼 쉼표로 구분해서 하나의 배열에 담아. `[값1] [값2]`처럼 따로 쓰지 마.
   - 개념 비교나 상태별 정리처럼 표로 나타내기 좋은 내용은 적극적으로 표를 써. 단, 표 앞뒤에는 반드시 빈 줄을 넣고, 리스트(불릿) 안에 표를 넣지 마. (안 지키면 표가 깨져서 텍스트로 떠버려)
5. 다 쓰면 나에게 먼저 보여줘. 내가 좋다고 하기 전에는 커밋하지 마.
6. 내가 확인하면 커밋하고 push해줘.
