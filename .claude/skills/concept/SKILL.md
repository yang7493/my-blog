# 개념 설명하고 정리하기

내가 개념을 물어보면 아래 순서로 해줘.

1. 먼저 대화로 설명해줘.
   - 한 줄 정의부터 말해줘.
   - 필요하면 조금 더 풀어서 설명해줘.
   - 가능하면 실제 예시나 비유를 들어줘.
   - 헷갈릴 수 있는 비슷한 개념이 있으면 차이점도 같이 짚어줘.

2. 방금 설명한 내용을 가지고 `_posts/`에 글을 만들어줘.
   - 파일 이름과 머리말은 `CLAUDE.md` 규칙을 따라.
   - front matter는 파일 맨 위에 딱 한 번만 써. 절대 두 번 쓰지 마.
   - title은 물어본 개념 이름으로 해줘 (예: "브랜치란?").
   - categories나 tags처럼 배열 값은 `[값1, 값2]`처럼 쉼표로 구분해서 하나의 배열에 담아. `[값1] [값2]`처럼 따로 쓰지 마.
   - 본문은 "정의" / "설명" / "예시" 섹션으로 나눠서 써.
   - 표를 쓸 경우, 표 앞뒤에 반드시 빈 줄을 넣고, 리스트(불릿) 안에 표를 넣지 마.

3. 다 쓰면 나에게 먼저 보여줘. 내가 좋다고 하기 전에는 커밋하지 마.
4. 내가 확인하면 커밋하고 push해줘.
